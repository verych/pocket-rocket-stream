Privacy Policy

Pocket Rocket Stream processes only the information needed to find and save media selected by the user. Processing takes place locally on the user's device.

1. Scope and purpose

This Privacy Policy describes how the Pocket Rocket Stream browser extension handles user data. The extension's single purpose is to detect media streams available on a page selected by the user and save them, locally merging compatible video and audio tracks when needed.

2. Information handled

To provide its user-facing functionality, the extension handles the following Chrome Web Store data categories:

  • Web history: the URL of the active page and URLs of resources requested by that page.
  • User activity: technical network-request events required to recognize media streams. The extension does not log keystrokes, mouse movement, or unrelated clicks.
  • Website content: accessible media elements, links, stream metadata, titles, formats, quality information, and technical response metadata such as MIME type, status, Content-Length, and Content-Range.

The extension does not request or intentionally handle names, postal or email addresses, health information, financial information, passwords, authentication credentials, private communications, or precise location.

3. How information is used

Information is used solely to scan the user-selected page, identify downloadable media, display available formats, download the resource selected by the user, diagnose failures, and merge compatible video and audio tracks locally. It is not used for any unrelated purpose.

4. Local storage and retention

  • Interface language and developer-mode preferences remain in local extension storage until changed, reset, or the extension is removed.
  • Temporary download jobs and diagnostic events are kept in browser session storage for the current browser session.
  • Large media tracks may be written to private on-device OPFS storage while downloading and merging. The extension removes temporary files after normal completion or cancellation. If a browser or device interruption prevents cleanup, files remain only in the extension's local storage until browser storage is cleared or the extension is removed.
  • The completed file is saved through Chrome Downloads at the user's request and remains under the user's control.

Diagnostic reports are visible only when Developer mode is enabled. Known signed tokens and authorization parameters are redacted from displayed diagnostic URLs. A report leaves the device only if the user explicitly chooses to copy and share it.

5. Network access and disclosure

By default, the extension receives temporary access to the active tab after the user clicks its toolbar icon. Access to a particular media CDN may be requested when the user starts a download. The user may separately enable or revoke early detection access for HTTP and HTTPS pages.

When the user requests a download, the extension connects directly to the source website or its CDN. These connections are necessary to retrieve the selected media and are subject to the source service's own privacy practices. The extension does not add a developer-operated recipient.

6. Sharing, sale, and advertising

The developer does not receive, sell, rent, share, or transfer user data to third parties. User data is not used for advertising, profiling, creditworthiness, lending, or any purpose unrelated to the extension's single purpose. The developer does not permit humans to read user data.

7. Security and remote code

Pocket Rocket Stream contains no analytics and executes no remotely hosted JavaScript or WebAssembly. Runtime code is packaged with the extension. Network access is limited to the page and media resources required for the feature initiated by the user.

8. User controls

Users can avoid processing by not opening the extension, revoke optional website access from the extension or Chrome settings, clear browser extension data, delete downloaded files, or uninstall the extension. Uninstalling removes storage owned by the extension from Chrome.

9. Limited Use compliance

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

10. Changes to this policy

This policy may be updated when the extension's functionality or legal requirements change. The effective date at the top of this page will be updated. Material changes to data practices will be disclosed before the changed practices take effect.

11. Contact

For privacy questions, contact pocket-rocket-stream@verych.ru.

1. Область действия и назначение

Настоящая Политика описывает обработку данных браузерным расширением Pocket Rocket Stream. Единственная цель расширения — находить медиапотоки на выбранной пользователем странице и сохранять их, при необходимости локально объединяя совместимые видео- и аудиодорожки.

2. Обрабатываемая информация

Для выполнения видимой пользователю функции расширение обрабатывает следующие категории Chrome Web Store:

  • История веб-поиска и посещений: URL активной страницы и адреса ресурсов, запрошенных этой страницей.
  • Действия пользователя: технические события сетевых запросов, необходимые для распознавания медиапотоков. Расширение не регистрирует нажатия клавиш, движения мыши или несвязанные клики.
  • Содержимое сайтов: доступные медиаэлементы, ссылки, метаданные потоков, названия, форматы, качество и технические метаданные ответа, включая MIME-тип, статус, Content-Length и Content-Range.

Расширение не запрашивает и намеренно не обрабатывает имена, почтовые или электронные адреса, медицинские и финансовые данные, пароли, данные аутентификации, личную переписку или точную геолокацию.

3. Использование информации

Информация используется исключительно для сканирования выбранной страницы, определения доступных медиа, отображения форматов, загрузки выбранного ресурса, диагностики сбоев и локального объединения совместимых видео- и аудиодорожек. Для посторонних целей информация не используется.

4. Локальное хранение и сроки

  • Настройки языка интерфейса и режима разработчика хранятся локально до изменения, сброса или удаления расширения.
  • Временные задания загрузки и диагностические события находятся в сессионном хранилище браузера в течение текущей сессии.
  • Большие медиадорожки могут временно записываться в закрытое локальное OPFS-хранилище во время загрузки и объединения. После штатного завершения или отмены расширение удаляет временные файлы. Если очистке помешало аварийное закрытие браузера или устройства, файлы остаются только в локальном хранилище расширения до очистки данных браузера или удаления расширения.
  • Готовый файл сохраняется через Chrome Downloads по запросу пользователя и остаётся под контролем пользователя.

Диагностические отчёты видны только при включённом режиме разработчика. Из отображаемых URL удаляются известные подписанные токены и параметры авторизации. Отчёт покидает устройство только в случае, если пользователь самостоятельно скопировал и передал его.

5. Сетевой доступ и раскрытие

По умолчанию расширение получает временный доступ к активной вкладке после нажатия пользователем на его иконку. При запуске загрузки может быть запрошен доступ к конкретному CDN. Пользователь может отдельно разрешить или отозвать раннее обнаружение на HTTP- и HTTPS-страницах.

По запросу пользователя расширение подключается напрямую к исходному сайту или его CDN для получения выбранного файла. На такие соединения распространяется политика конфиденциальности исходного сервиса. Расширение не добавляет сервер или иного получателя, управляемого разработчиком.

6. Передача, продажа и реклама

Разработчик не получает, не продаёт, не сдаёт в аренду, не раскрывает и не передаёт пользовательские данные третьим лицам. Данные не используются для рекламы, профилирования, определения кредитоспособности, кредитования или иных целей, не связанных с единственным назначением расширения. Разработчик не разрешает людям читать пользовательские данные.

7. Безопасность и удалённый код

Pocket Rocket Stream не содержит аналитики и не выполняет JavaScript или WebAssembly с удалённых серверов. Весь исполняемый код включён в пакет расширения. Сетевой доступ ограничен страницей и медиаресурсами, необходимыми для запрошенной пользователем функции.

8. Управление данными

Пользователь может не запускать обработку, не открывая расширение; отозвать опциональный доступ к сайтам в расширении или настройках Chrome; очистить данные расширения; удалить скачанные файлы либо удалить само расширение. При удалении Chrome удаляет принадлежащее расширению хранилище.

9. Соответствие Limited Use

Использование информации, полученной через API Google, соответствует Chrome Web Store User Data Policy, включая требования Limited Use.

10. Изменения политики

Политика может обновляться при изменении функций расширения или требований законодательства. Дата в начале страницы будет обновлена. О существенных изменениях правил обработки данных будет сообщено до вступления таких изменений в силу.
